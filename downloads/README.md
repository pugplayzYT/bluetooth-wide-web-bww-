# BWW downloads

This page is generated by GitHub Actions after both build jobs pass. Bookmark this page: the links below always point to the latest published packages. No tags are required. Older versioned files, if present, are historical downloads.

## Android app

[Download Android 0.6.4](https://raw.githubusercontent.com/pugplayzYT/bluetooth-wide-web-bww-/main/downloads/Bww-Android-0.6.4.apk) — Android 8 or newer. Allow notifications for background-upload status. Official releases use a private, stable signing key. See [signing and update compatibility](../ANDROID_SIGNING.md) before updating a legacy CI-signed installation.

## Windows server and Bluetooth sync

[Download Windows host/sync 0.6.2](https://raw.githubusercontent.com/pugplayzYT/bluetooth-wide-web-bww-/main/downloads/Bww-Windows-Sync-0.6.2.zip) — extract and run Bww.Server.exe, or Sync-BWW.bat for reviewed website sync. No .NET installation required.

## ESP32 firmware

[Download precompiled firmware 0.6.2](https://raw.githubusercontent.com/pugplayzYT/bluetooth-wide-web-bww-/main/downloads/Bww-ESP32-Binaries-0.6.2.zip) — includes the matching crash-decoder ELF and flashing instructions.

[Download PlatformIO sources 0.6.2](https://raw.githubusercontent.com/pugplayzYT/bluetooth-wide-web-bww-/main/downloads/Bww-ESP32-PlatformIO-0.6.2.zip) — extract and open the esp32 folder. Requires an original ESP32 with Bluetooth Classic. Back up the SD card /bww folder before upgrading.

## SD-copy tool

[Download BWW SD Copy](https://raw.githubusercontent.com/pugplayzYT/bluetooth-wide-web-bww-/main/downloads/Bww-SD-Copy.zip) — Python 3.10+, copies accounts and websites between PC and SD formats without formatting the card.

## Integrity

[SHA-256 checksums](SHA256SUMS.txt) cover every downloadable APK/ZIP in this directory. The official Android certificate SHA-256 is `947c02515d123adca43ef1b3ce04c6c0ebb590c89db7fe31f290636c6a1c22d0`. Private keys and passwords are never included in downloads. Android app fixes must increase versionName and versionCode; same-version code changes are rejected by packaging.
